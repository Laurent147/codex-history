How these rates are used

Estimates use uncached input × input rate + cached input × cache rate + output × output rate. Cached tokens are already included in input totals, and reasoning tokens are included in output totals.

Long-context uplifts apply only when individual request sizes are available and exceed the model’s threshold. Snapshot-only sessions use base rates. Estimates exclude fast or priority tiers, regional premiums, tool fees, taxes, and your subscription billing.
